# inputs/ — CSV 입력 폴더

Meta Business Suite → 인사이트 → 콘텐츠 → **내보내기(CSV)** 파일을 이 폴더에 올리면
(GitHub 웹: `Add file → Upload files`) `insta-analysis` 워크플로가 자동으로 실행되어 결과를 `results` 브랜치에 올립니다.

- 여러 기간의 파일을 계속 추가해도 됩니다 — 실행할 때마다 전부 병합하고 중복을 제거합니다.
- 분석 기준 시각은 **파일을 올린(커밋한) 시각**으로 자동 계산합니다(게시 7일 미만 게시물 제외용).

⚠️ **이 저장소가 공개(public)이면 여기에 올린 CSV도 전 세계에 공개됩니다.**
저장소를 Private으로 바꾸거나, API 방식(Secrets에 토큰 등록)을 쓰세요. 실행기는 공개 저장소에 실제 데이터
결과를 올리는 것을 기본적으로 막습니다.
